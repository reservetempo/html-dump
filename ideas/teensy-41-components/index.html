How an encoder shows its position

A rotary encoder has two outputs, A and B. When you turn the shaft, each output changes between on (1) and off (0). There is a quarter of a cycle between the two outputs.

The sequence of the changes shows the direction. The number of changes shows the distance. This method is known as quadrature.

The processor counts the changes. The program makes a message from the count and sends it through USB. The computer can see the board as a MIDI device, a serial port or a game controller.

An encoder that you turn by hand makes, at most, some thousands of changes each second. The processor does 600 million cycles each second. Thus the task uses a very small part of it.

The four quadrature decoders count the changes with no work for the program. They operate on specified pins only. If you have more than four encoders, the program can count the changes itself on any pin.

How the power moves

The board gets 5 V from the USB cable and changes it into the voltages that each part needs. The red paths supply the red components.

A new board for this project only

Method 1: Keep the processor and remove the red parts

The board keeps the black components. It works with the Teensy software and your program does not change.

But this method is difficult. The processor has 196 contacts below the chip, and you cannot solder them by hand. The processor is also much more powerful than the task needs.

Method 2: Use a smaller processor

This is the usual method for a board with one task. A small microcontroller with USB can read many encoders easily. Examples are the ATmega32U4, the RP2040 and the small STM32 chips with USB.

  • One small microcontroller with USB.
  • One USB connector.
  • One regulator. Some chips operate directly from 5 V and do not need it.
  • One crystal. Some chips have an accurate internal clock and do not need it.
  • One flash chip, but only if the microcontroller has no internal program memory.
  • One button for program mode.
  • One 3-pin connector for each encoder.
  • A small number of capacitors and resistors.

The chips above are examples, not a final selection. The program from your Teensy will need changes for a different chip.
