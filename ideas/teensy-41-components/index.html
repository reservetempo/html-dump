Teensy 4.1, part by part

The Teensy 4.1 is a small development board. It has a very fast processor and many connections. Your project uses only a small part of it.

Your project: rotary encoders send their position to a computer. A digital synthesizer on the computer uses the position values.

This page shows each component on the board and tells you what it does. Red components are not necessary for your project. If you make a new board for this project only, you can remove them.

Necessary for the project Not necessary. Remove on a new board.

SECTION 1The task of the board

The board has one task. It reads the encoders and tells the computer how far each one turned. The diagram shows the path of the signal.

How an encoder shows its position

A rotary encoder has two outputs, A and B. When you turn the shaft, each output changes between on (1) and off (0). The two outputs do not change at the same time. There is a quarter of a cycle between them.

The sequence of the changes shows the direction. The number of changes shows the distance. This method is known as quadrature.

An encoder that you turn by hand makes, at most, some thousands of changes each second. The processor on the Teensy 4.1 does 600 million cycles each second. Thus the task uses a very small part of the processor.

SECTION 3Components that the project uses

These components stay on the board. Together they are the minimum to read encoders and speak USB.

1Processor

NXP i.MX RT1062 · ARM Cortex-M7 · 600 MHz
Necessary

This is the largest chip on the board. It runs your program. It reads the encoder signals, counts them and sends the count through USB.

The chip contains 1 MB of RAM. It contains no memory for the program. Thus it needs the flash memory (2).

You need a processor, but not this one. Refer to Section 7.

2Flash memory

Winbond W25Q64JV · 8 MB
Necessary

This chip keeps your program when the power is off. At power-on, the processor reads the program from it.

A program for encoders uses less than 1% of the space.

3Bootloader chip

NXP MKL02 with PJRC software
Necessary

This small chip puts a new program into the flash memory. It starts when the Teensy Loader sends an upload or when you push the Program button. It can also repair the board if your program fails.

A new board with the same processor needs this chip to work with the Teensy software. PJRC sells it as a separate part.

424 MHz crystal

Main clock reference
Necessary

The crystal gives the processor an accurate time reference. All speeds in the processor come from it. USB communication needs this accuracy.

5Micro-USB connector

USB device port · 480 Mbit/s
Necessary

This is the connection to your computer. The cable supplies 5 V power to the board. The same cable carries the encoder data to the computer and new programs to the board.

6Power parts

3.3 V regulator (TLV75733P) · fuse · inductor · capacitors
Necessary

The USB cable supplies 5 V, but the chips use 3.3 V. The regulator decreases the voltage. The fuse protects the computer if there is a short circuit.

The inductor is a part of a second converter inside the processor. The capacitors keep each voltage stable. Refer to Section 6.

7Program button

Push button
Necessary

Push this button to put the board into program mode. Usually the upload starts automatically. The button is the manual alternative, and it is necessary for a repair.

8Pins for the encoders

2 signal pins for each encoder · 1 GND pin
Necessary

Each encoder uses two signal pins, A and B. The common pin of the encoder connects to GND. A push switch in the encoder uses one more pin.

Four encoders need 8 signal pins. The map shows pins 0 to 7 as an example. Some encoder types also need a power pin.

SECTION 4Components that the project does not use

These components do no work in your project. A board for this project only does not need them.

9All other pins

Approximately 45 of 55 input/output pins · VIN pin
Not necessary

The board has 55 input/output pins. 42 of them are on the two long sides. The other 13 go to the SD socket and to the memory positions on the bottom.

These pins supply analog inputs, serial ports, audio, CAN bus and more. Your project uses approximately 8 of them. The VIN pin is for external power, and USB already supplies the power.

10Ethernet chip and pins

TI DP83825I PHY · 6-pin header
Not necessary

This chip changes network data from the processor into the electrical signals for a network cable. It does work only if you add an Ethernet jack to the 6 pins.

Your data goes through USB. A network connection is not necessary.

11USB host port

5 pins · TPD3S014 power switch
Not necessary

This second USB port lets you connect USB devices to the Teensy, for example a keyboard. The switch chip controls the 5 V power to that device and limits the current.

Your board is a USB device only. It is not a host.

12microSD socket

Card socket on a fast 4-bit interface
Not necessary

The socket holds a memory card for files, for example audio recordings or data logs. Your project stores no files.

13Clock crystal, VBAT pin and On/Off pin

32.768 kHz crystal · coin cell input · power button input
Not necessary

The small crystal operates a clock for the date and the time. A 3 V coin cell on the VBAT pin keeps this clock on when the power is off. The On/Off pin lets a button switch the 3.3 V power.

An encoder board does not need the date, the time or a power button.

14LED

Orange LED on pin 13
Not necessary

Programs flash this LED to show that they run. The task does not need it.

It is useful for tests and it costs very little. You can keep it on a new board if you want a simple indication.

15Memory positions on the bottom

2 empty positions for 8-pin PSRAM or flash chips
Not necessary

You can solder more memory here: two RAM chips, or one RAM chip and one flash chip. On a new Teensy the positions are empty.

Your project uses a very small quantity of memory. More memory is not necessary.

SECTION 5Inside the processor

Many functions of the Teensy 4.1 are not separate components. They are circuits inside the processor chip. The diagram shows the primary circuits.

You cannot remove a circuit from a chip. But you can select a smaller chip that does not have the red circuits.

The four quadrature decoders count the changes with no work for the program. They operate on specified pins only. If you have more than four encoders, the program can count the changes itself on any pin. The Teensy software has a library for each method.

SECTION 6How the power moves

The board gets 5 V from the USB cable and changes it into the voltages that each part needs. Three power paths go to parts that your project does not use.

SECTION 7A new board for this project only

There are two methods to make the new board.

Method 1: Keep the processor and remove the red parts

The board keeps components 1 to 8. It works with the Teensy software and your program does not change.

But this method is difficult. The processor has 196 contacts below the chip, and you cannot solder them by hand. The processor is also much more powerful than the task needs.

Method 2: Use a smaller processor

This is the usual method for a board with one task. A small microcontroller with USB can read many encoders easily. Examples are the ATmega32U4, the RP2040 and the small STM32 chips with USB.

With a small microcontroller, the board becomes very simple:

  • One small microcontroller with USB.
  • One USB connector.
  • One regulator. Some chips operate directly from 5 V and do not need it.
  • One crystal. Some chips have an accurate internal clock and do not need it.
  • One flash chip, but only if the microcontroller has no internal program memory.
  • One button for program mode.
  • One 3-pin connector for each encoder.
  • A small number of capacitors and resistors.

The chips above are examples, not a final selection. Make the selection from the number of encoders and from the software that you want to use. The program from your Teensy will need changes for a different chip.

The maps on this page are simplified drawings. They show which components are on the board, not their accurate positions. For accurate data, refer to the PJRC Teensy 4.1 page and its schematic.
